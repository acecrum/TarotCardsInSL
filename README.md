# Tarot Cards In SCP: Secret Laboratory

## This plugin requires [RueI](https://github.com/pawslee/RueI/releases/)
Download it and put it inside your plugins folder for the plugin to work.

## Cards
All 22 Major Arcana Tarot cards are added in this plugin and there is support for all humans and nearly every SCP ([SCP-079 is excluded is due to issues with ServerSpecific Inputs for them](https://github.com/northwood-studios/LabAPI/issues/453)).
Certain Tarot cards will have different effects for SCPs compared to humans.

## Config
| Config Setting             | What it does                                                                                                                                                                                                                                                                        | Default Value                   |
|:---------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------|
| XXXXSpawnWeight            | This controls the spawn weight for each card and allows for more overtuned cards to appear less.                                                                                                                                                                                    | N/A                             |
| EnableMagician             | This enables The Magician card, this card is disabled by default and should **NOT** be enabled in a actual server with real players.<br/>This card gives off the effect of hard aim locking and can easily be confused for actual cheating. Enable at your own risk.                | false                           |
| EnableCardLights           | Enables card lighting for tarot cards. Disable to remove card lights from spawning on the client                                                                                                                                                                                    | true                            |
| TarotMasterSpawnChance     | Spawn chance for the Tarot Master.<br/>1f = 100% chance to spawn and 0.05f means around a 5% chance to spawn.                                                                                                                                                                       | 0.05f                           |
| TarotMasterSpawnCap        | Controls how many Tarot Masters can be alive at once before none can spawn anymore.                                                                                                                                                                                                 | 1                               |
| MininumCardCraftingTime    | The mininum time it takes for a Tarot Master to craft a card for another player.                                                                                                                                                                                                    | 90f                             |
| MaximunCardCraftingTime    | The maximun time it takes for a Tarot Master to craft a card for another player.                                                                                                                                                                                                    | 150f                            |
| EnableTarotMasterLight     | Enables the light the Tarot Master spawns with. Disabling it will not spawn the light                                                                                                                                                                                               | true                            |
| TarotMasterLight           | Sets the color for the light seen on the Tarot master                                                                                                                                                                                                                               | r: 0<br/>g: 1<br/>b: 1<br/>a: 1 |
| EnableDataStoring          | Enables data storing for the plugin. The only thing that is stored is a players UserID. This is used to store if a player has properly set their binds and disables the reminder hint for them. (Players with "Do Not Track" active will not have their data stored no matter what. | true                            |
| EnableReminderHint         | Shows the reminder hint when a player joins. Disable this to not allow this to be shown to the player                                                                                                                                                                               | true                            |
| EnableTechnicalHints       | Enables more technical hints on what a card actually does instead of vague hints on what it does.                                                                                                                                                                                   | false                           |
| EnableTutorialInteractions | Allows for some cards to interact with the Tutorial class. Enable if you have a plugin that utilizes the Tutorial class for gameplay reasons or non-adminstrative reasons.                                                                                                          | false                           |
| EnableScpPickUp            | Allows SCPs to pick up Tarot cards with their interact key. Disabling removes SCP's from being able to pick up Tarot cards.                                                                                                                                                         | true                            |

## Commands
| Command Name & Alias  | What it does                                                                                                                                                                                               | Syntax                                 |
|:----------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------|
| addcard, ac           | Adds a Tarot card directly onto a player you specify.<br/>"addcard list" can be used to get a list of all registered cards in the plugin                                                                   | addcard [PlayerID] [CardName]          |
| forceactivate, fa     | Forces a players active card to be activated.                                                                                                                                                              | forceactivate [PlayerID]               |
| forcetarotmaster, ftm | Forces you or a specified PlayerID into a Tarot Master (Turns the executer into a Tarot Master if no PlayerID is provided)                                                                                 | forcetarotmaster [PlayerID (optional)] |
| hascard, hc           | Gets what card a player has if they have one                                                                                                                                                               | hascard [PlayerID]                     |
| removecard, rmc       | Removes and deletes a player's Tarot Card if they have one                                                                                                                                                 | removecard [PlayerID]                  |
| spawncard, sp         | Spawns a Tarot card directly on top of the executer<br/>"spawncard list" can be used to get a list of all registered cards in the plugin<br/>"spawncard all" will spawn all registered cards when executed | spawncard [CardName]                   |
